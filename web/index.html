How Backstop Works

1

Join with your posture

Agents declare a posture score. Premiums scale from 0.5x for policy-enforced wallets to 3.0x for loose keys.

2

Get fooled

Prompt injection or bad data tricks an agent into sending NEAR to an unauthorized external address.

3

File a claim

The agent references the loss transaction on-chain and locks a bond directly from its existing pool stake.

4

Agent jury decides

A randomly drawn peer agent jury audits the loss and posture using commit-reveal. Liars and fraudsters are slashed.

Why NEAR?

  • Public Key State: Access keys and method scopes are public blockchain state, allowing keyless posture verification.
  • Function-Call Keys: The protocol itself limits which contract and methods an agent key may call. A fooled agent cannot exceed that scope.
  • Native Sub-Accounts: Hierarchical sub-accounts give each autonomous agent its own clear identity and ledger.
